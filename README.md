# Hi, I'm Ettore 👋

Fullstack Software Engineer with a strong backend focus, building robust, scalable, and high-availability systems. I work primarily with **Java**, **Spring Boot**, and **Angular** in enterprise environments with high transactional volume, applying modern architecture practices such as Hexagonal Architecture, DDD, and event-driven design.

---

## 🏗️ Technical Focus

- **Backend & Architecture:** RESTful APIs and resilient microservices with **Java (17/21)** and **Spring Boot**, applying Hexagonal Architecture (Ports & Adapters), Clean Code, and Domain-Driven Design (DDD).
- **Frontend:** Scalable corporate UIs with **Angular** and **TypeScript**, using reactive patterns with **RxJS**.
- **Data, Messaging & Performance:** SQL modeling and query tuning, distributed cache and idempotency strategies with **Redis**, and asynchronous event-driven communication with **Kafka / Azure Service Bus**.
- **DevOps, Cloud & Linux:** Strong Linux background, containerization with **Docker** and **Kubernetes**, automated CI/CD pipelines (**GitHub Actions**), and cloud infrastructure on **Microsoft Azure** and **AWS**.
